## Phase 31 — Skill Intelligence

**Plan:** `docs/ai/plans/2026-03-26-phase31-skill-intelligence.md`
**ADR:** `docs/ai/decisions/041-skill-intelligence.md`

### What this phase is

Makes the skill ecosystem self-organising: skills discover themselves via clustering, load on demand when matched to queries, resolve dependencies automatically, bridge overlapping concepts, and share across instances. The agent acquires and deploys domain expertise autonomously.

### Key deliverables

- Skill dependency graph: topological sort for safe multi-skill activation; auto-resolve dependencies or reject conflicts
- Neural skill embeddings: compute HyperVec prototype per skill; enable semantic matching (Phase 28 routing can auto-load relevant skills)
- Skill-aware routing: lazy loading of skills based on query similarity; auto-deactivation of idle skills
- Skill discovery from reasoning: cluster co-activated symbols during consolidation; detect novel skill candidates; LLM names them
- Dynamic skill synthesis: fill knowledge gaps (Phase 11j) by gathering resources and authoring new skills autonomously
- Skill sharing protocol: export/import `.akhskill` archives with checksums; recipe references remote skill URLs
- Cross-skill inference: detect and bridge overlapping concepts via generated bridge rules; multi-skill provenance
- Skill curriculum: learning progression per skill (Bloom levels, prerequisite concepts, assessment queries)

### Dependencies

Phase 30 (procedural skills), Phase 26d (neural bridge), Phase 28 (n akh router).

### Why this priority

Enables skill ecosystem but doesn't block individual skill functionality.

## Summary
Implement Phase 31 of the agent architecture to make the skill ecosystem self-organizing. This introduces neural embeddings for lazy matching, a dependency graph for safe multi-skill activation, automated skill discovery/synthesis via LLM clustering, and a portable `.akhskill` sharing protocol.

## Approach
Start by extending `anima-core` and `anima-proto` with the new skill primitives (curriculums, bridge rules, and remote URLs) while migrating `anima-db` to store skills, their relationships, and neural embeddings (potentially requiring `pgvector`). 
In `anima-ai`, incorporate the embedding logic (generating HyperVec prototypes) and build the semantic clustering subsystem to detect and synthesize new skills from reasoning contexts. 
In `anima-agent`, implement a robust topological sorter to safely resolve skill dependency graphs and a dynamic router for lazy loading/deactivation. Finally, implement standard checksum validation and unpack/pack logic in `anima-agent` to support the `.akhskill` archive specification.
