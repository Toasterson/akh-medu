## Goal

Get the tool-native BabyLLM (`small_8k`, 33.4M, best measured candidates 401,577 / 355,735 at 1259/1272 tools) through its release gate **without a cloud pod unless the local machine measurably cannot do it**, with the Rust harness (`grug-train` on Burn) as the only training driver and akh-medu's own engine (rule engine, event calculus, causal manager, TMS) as the episode generator and verifier. The three blockers are `memory_write` (nested-value copying), `reactor_manage` (tool-call envelope under non-English prompts) and `structured_task_create` (create-vs-update discrimination).

## Decisions (ADR 106)

1. **Burn on Metal is the local lane.** Add a `metal` feature to `grug-train` (`burn/metal`), `GpuBackend = burn::backend::Wgpu<f32>`, `gpu_device()` → `WgpuDevice`, mutually exclusive with `gpu`/`cuda`; keep `grad_checkpointing` honoured. No model code changes (every trainer is generic over `B: AutodiffBackend`). If wgpu/MSL throughput is below the gate in §Budget, the fallback inside the same harness is a forked Burn backend over MLX (`mlx-rs`), not Python.
2. **Short-context remediation.** The blockers are tool-contract families; remediation windows train at 2048/4096 context on the RoPE-extended checkpoint (ADR 104 train-short/fine-tune-long), and the release gate stays at its unchanged 8192 sentinels.
3. **The engine is the teacher and the judge.** Episodes for the knowledge and tool families are generated by akh-medu's engine through the recovered Rust bridges (`akh_symbolic_episode_bridge`, `akh_temporal_incident_bridge`, `akh_temporal_validity_probe`); symbolic completion produces the corrected action targets; causal `predict_effects`/`verify_prediction` and event-calculus `holds_at` produce per-step rewards and validity labels (joins P3-RL, WI-301). Python MLX scripts are reference tooling for comparison, not the training driver.
4. **Pod only on measured failure.** A Runpod restart needs a written throughput measurement from P6.1 showing the local lane cannot complete the planned remediation inside the budget, plus operator approval and a dollar cap in the WI thread.

## Experiments (engine + world model in training)

Each experiment trains the same checkpoint with and without the treatment, scores the unchanged sentinels, and records the delta. Controls are mandatory; a treatment without a control is not a result.

- **E1 symbolic completion as target.** Treatment: training targets are the engine-completed actions (the completion that fixed 7 + 4 wrong proposals in the 2026-09-12 replay); control: raw authored targets. Hypothesis: copy-faithful families (`memory_write`, `study_note_*`) gain because the completed target is always schema-valid and value-exact.
- **E2 temporal validity context.** Treatment: the prompt carries the event-calculus current-truth projection (`holds_at` after the arrival-order fix); control: raw event list. Measured on revision/temporal families and on `reactor_manage` under late revocations. Hypothesis: stale-intent actions drop to zero without hurting other families.
- **E3 causal verification as step reward.** Treatment: per-step reward from `CausalManager::predict_effects` → `verify_prediction` on engine replay (P3-RL A2 machinery, WI-301); control: sequence-level loss only. Measured on multi-step tool families and `structured_task_create` (create-vs-update is a precondition question).
- **E4 revision curriculum on exact-owned retraction.** After `tests/exact_owned_revision.rs` is green: episodes where a sourced correction retracts an owned edge and the model must act on the revised graph; control: no retraction (append-only). Measured on `knowledge.revise` and `memory_write`.
- **E5 (later) engine-generated curriculum breadth.** Replace the authored 24-episode oracle with engine-generated families across command grammars; measure held-out family transfer. Runs only after E1–E3 have controls recorded.

## Budget and gates

- Local lane gate (P6.1): a remediation window of 2,000 sibling + base records at 2048 context must complete in ≤ 24 h on the M2; the 8192 release-gate sentinel evaluation (constrained decode) must complete in ≤ 12 h. Below that, P6.6 opens.
- Pod cap if ever needed: ≤ 6 h A100 (≈ $10) per approved stage; balance at last check ≈ $78.
- Every window, every gate and every experiment writes a RESULT doc under `training/results/` and a thread post on its WI; monitor events go to the Agent Board run thread `01a09a63-7745-7a30-8b7f-5b7e355e419e` (`coordination/status@v1`), never to a chat wakeup.
