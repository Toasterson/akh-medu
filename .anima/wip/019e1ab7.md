## Summary
Every entity incorrectly maps to the identical set of ~108 outgoing knowledge graph triples. This is likely caused either by a missing filtering clause (creating a SQL Cartesian product) during database retrieval or by state leakage across loop iterations during AI-driven knowledge extraction.

## Approach
Determine whether the hallucination occurs at read-time or write-time. For a read-time issue, inspect the graph retrieval queries in `anima-db` to verify that join conditions and `WHERE` clauses correctly filter by the specific entity ID. For a write-time issue, inspect the processing loops in `anima-ai` and `anima-triage` to ensure that data structures holding extracted triples are dropped or re-initialized per entity. Fix the query or loop, add a unit test matching multiple distinct entities to verify independent triple sets, and provide a SQL migration to purge corrupted associations if the database was polluted.
