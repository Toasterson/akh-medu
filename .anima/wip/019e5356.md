## Description

## Summary
Integrate the existing `apply_seed` tool into the workspace creation or initialization cycle. This ensures that the 246 foundational triples spanning architecture, common-sense, computing, identity, and ontology are loaded to establish the Knowledge Graph (KG) base ontology.

## Approach
Identify the workspace bootstrap sequence, which likely occurs either during project creation on the server or during the initial startup sequence of the executor container (`anima-exec`). Inject a routine that invokes the `apply_seed` tool for all 5 seed packs immediately after the workspace/KG environment is initialized. To handle restarts safely, implement an idempotency check—such as querying the KG for a known foundational node or checking a "seeded" state flag—so that the seed packs are only applied once during the first "awaken" cycle.

## Files likely to change
* `crates/anima-exec/src/main.rs` (or equivalent bootstrap module)
* `crates/anima-agent/src/main.rs` (if execution needs to be triggered from the host side)
* `crates/anima-server/src/services/project.rs` (if seeded directly at project creation)
