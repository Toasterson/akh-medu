## Description

Ennead members exist: Tecton, Thoth, Horus, Set, Maat/Ma'at, Khnum. But only Tecton has a psyche (sage-dominant Noctfact). Other members are empty shells — they exist only as targets of has-member. ## Summary
Expand the `Agent` domain model to include character sheet attributes like archetypes, roles, and domain affiliations. This will allow the AI layer to generate distinct personas for Ennead members (Thoth, Horus, Set, Maat, Khnum) rather than treating them as empty shells.

## Approach
Introduce a `Psyche` or `CharacterSheet` structure in `anima-core` containing archetypes, roles, and domain affiliations, and attach it to the `Agent` type. Update the gRPC definitions in `anima-proto` to reflect these new fields. In `anima-db`, write a SQL migration to add a JSONB column to the agents table and update the repository layer to persist and load it. Update `anima-ai` to inspect the agent's distinct identity and dynamically inject their archetype and roles into the LLM system prompt. Finally, update the database bootstrap/seeding logic to populate the specific configurations for the Ennead members, and expose the attributes in the desktop UI's team views if required.
