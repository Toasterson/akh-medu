## Summary

Replace the current logits-as-stand-in input to `NeuralVsaBridge::encode` with a faithful intermediate hidden-state vector from the source LLM. Today `CandleBackend::extract_hidden_state` (src/nlu/candle_backend.rs:275) returns the last-token logits because candle-transformers does not expose hooks for the residual stream — that's the gap to close.

Acceptable for the bring-up demo; *not* acceptable for the production thesis that "frontier LLMs implement an approximate VSA, akh-medu has the exact one" (ADR 052). As long as the bridge consumes logits, Pattern A is a softmax-shaped proxy of the true latent and Pattern B (ADR 055) cannot fairly compare against akh-medu's symbolic Loop.

## Two paths to evaluate (~1 week investigation pass)

1. **Path A — patch candle-transformers** to add a hook API for Qwen2 (and ideally a generic trait so other architectures inherit). Vendor in `vendor/candle-transformers/`, file upstream PR. ~600 LOC.
2. **Path B — model migration** to a candle-supported model with native hidden-state extraction. Candidates: Mistral 7B, Pythia (MIT licensed, designed for interpretability), GPT-NeoX, Llama 3 small variant. Add `src/llm/<model>_backend.rs`, retrain `NeuralVsaBridge` against the new hidden-state distribution. ~1,500 LOC + retraining time.

Decision criterion: faithful 1536-D (or comparable) hidden-state stream with the lowest maintenance burden and the cleanest licence story.

## Cross-cutting

Whichever path, the encoder weights in `NeuralVsaBridge` need to be re-fit. `BridgeTrainer` (src/vsa/neural_bridge.rs:253) infrastructure already exists.

## Acceptance gate

Re-encoding a held-out set of NLU phrases produces tighter `ItemMemory::search` similarity scores than the current logits-as-proxy baseline. Metric: mean nearest-neighbour cosine similarity. Improvement of ≥ 0.05 vs baseline = pass; lower = reopen investigation.

## Summary
Replace the current logits-based proxy in `NeuralVsaBridge::encode` with authentic intermediate hidden-state vectors extracted from the source LLM. This ensures a mathematically rigorous representation of true latents for the Vector-Symbolic-Architecture bridge, meeting the production requirements of ADR 054.

## Approach
Begin with a timeboxed evaluation to choose between Path A (vendoring and patching `candle-transformers` to expose residual stream hooks for Qwen2) and Path B (migrating to a model with native hidden-state extraction like Pythia or Mistral). Once the path is determined and the requisite extraction layer is implemented, update `CandleBackend::extract_hidden_state` to return the true hidden-state vector. Finally, execute the `BridgeTrainer` to refit the `NeuralVsaBridge` encoder against the new true-latent distribution, and confirm through evaluation that the mean nearest-neighbour cosine similarity in `ItemMemory::search` improves by ≥ 0.05 over the baseline.
