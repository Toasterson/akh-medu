## Summary
The agent's NLU component is generating invalid self-referential triples (e.g., `self → child-of → self`) during its OODA orientation loop. This fix introduces a programmatic filter to drop these meaningless cycles upon extraction to reduce noise and prevent database inflation.

## Approach
Implement a validation check inside the agent's knowledge extraction pipeline that prevents self-referential triples from being successfully emitted or persisted. First, update the domain model for agents/triples in `anima-core` to include a validation method that rejects edges where `source == target` for hierarchical predicates like `child-of` and `part-of`. Next, modify the OODA loop's NLU step—likely within `anima-exec` or `anima-ai`—to silently filter out these invalid triples from the LLM extraction output. Finally, update the LLM instructions/system prompt in `anima-ai` to explicitly discourage generating self-referential cyclic relationships.
