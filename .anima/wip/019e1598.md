## Description

CODE BUG — NOT MCP-fixable. OODA cycle creates summary entities (e.g. summary:Decide: tool=X, goal=Y) that trigger auto-completion goals like "Find part-of for summary:...". These artifact entities have no real knowledge value. Fix needed: filter summary entities from auto-completion goal generation, or constrain auto-completion goals to entities with kind not-equal summary. Workaround: leave Dormant/Suspended goals to age out.

## Summary
The agent's OODA cycle generates intermediate "summary" entities that inadvertently trigger useless auto-completion goals, leading to system noise and database contamination. The fix requires adding a filter to the auto-completion goal generator to exclude any entities explicitly typed as "summary".

## Approach
Locate the auto-completion goal generation logic within the agent runtime (likely running inside `anima-exec` or orchestrated by `anima-agent`). Modify the entity iteration or selection query that feeds the auto-completion logic to filter out entities where `kind == "summary"`. To keep the domain logic clean, add a helper method such as `is_ooda_artifact()` to the entity/agent domain types in `anima-core`. This encapsulates the check and makes it easy to exclude other artifact kinds in the future if needed. 

## Files likely to change
* `crates/anima-core/src/domain/agent.rs`
* `crates/anima-exec/src/` (Goal generation or OODA loop module, e.g., `goals.rs` or `ooda.rs`)
* `crates/anima-agent/src/` (As a fallback, if goal generation is handled host-side instead of in the executor container)

## Open questions
* Should we write a one-off database migration in `anima-db` or a cleanup script to proactively purge the existing 39% of useless goals, or strictly rely on the "age out" workaround mentioned in the ticket?
* Are there other internal OODA cycle artifacts besides `summary` (e.g., `thought`, `observation`, `trace`) that should be added to the exclusion list now?
* Is entity `kind` stored as a raw string, or is it a strongly-typed enum in `anima-core` that we need to update/match against?
