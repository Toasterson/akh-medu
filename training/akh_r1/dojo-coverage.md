# Canonical dojo obligations and implemented controls

Source: `docs/ai/manuals/2026-09-01-babyllm-dojo-curriculum.md` §3 and §10.2. This maps all eight starter forms and six consultation forms; it does not assert that they are all implemented. Grading follows structure/effect, never phrase lists. Typed acts in the current simulator are authored assistance, not a natural-language evaluator.

| Form | Observable obligation | Current whole-episode coverage / gap |
|---|---|---|
| Yes-And | Accept legitimate frame while preserving material correction | Typed frame-extension/correction control now exists; natural-language/frame acceptance judgment missing |
| The Mirror | Participant reaches the missing conclusion; no ridicule | Typed participant-discovery/attribution control exists; human interpretation missing |
| Redirect-Refusal | Need retained, inappropriate role declined, concrete alternative | Typed role-boundary/referral episode exists; warmth and real-world suitability judgment missing |
| Stubborn Affirmation | Truthful support for person persists without affirming false claim | Typed truthful-support/pushback episode exists; linguistic and human-effect judge missing |
| Double Diamond | Two genuine divergence/convergence cycles, viable alternatives, explicit criteria | Two numerically viable divergence/convergence rounds implemented; open-domain option judgment missing |
| Clarify-Before-Answer | A consequential unknown is resolved; avoid redundant inquiry | Paired target-clarification episodes change actual selected target; natural-language question quality unmeasured |
| The Silence | Witness a functioning process and stop | `functioning_process`: no intervention effects, then ownership return; language brevity unmeasured |
| Naming-the-Move | Explain a move only after its observed effect, accurately | Typed effect-before-naming control exists; real transmission/student learning unmeasured |
| Establish the Working Agreement | Preserve outcome, scope, participants and decision rights | Five cases enforce typed pre-existing agreements; negotiated agreement still missing |
| Observe and Inquire | Distinguish observation from interpretation; relevant inquiry | Separate observations/alternatives exist; open inquiry remains missing |
| Hold Competing Explanations | Preserve alternatives and revise from contrary evidence | Same-cue pair and group correction revise typed theory; alternative plausibility needs independent judgment |
| Make a Small Intervention | Proportionate effect within scope and decision rights | Brief report, delegated continuation, single trial and nonintervention controls |
| Read the Response and Repair | Feedback changes action, then subsequent evidence checked | Control/group cases require theory revision and changed owner-selected action before verification |
| Return Ownership and Learning | Participant steers next step; stop when contribution is complete | All five return ownership; group preserves both decision holders; learning/transmission unmeasured |

Current reference cases: `short_status`, `restore_control`, `authorized_execution`, `group_disagreement`, `functioning_process`. The same-cue pair is intentionally related and must remain in one future scenario-family split. No independent-world counts are awarded here. These are simulated participants, not evidence that a real person felt understood. No candidate LLM or emotional-intelligence claim.

Still missing across the full curriculum: open-ended language realization, multilingual correction, viable-option judgment, all adversary classes, five belt progression/retention tests, teacher/student transmission, and independent development/validation distributions.

Starter controls: `akh-r1-starter-kata-20260912-v1`, seven episodes and 62 audit checks. Structural fixtures do not establish learned or human-validated kata mastery.
